Use-Case Flowchart

All v1 use cases · Athlete Mindset Training Platform
A · Provision — workshop to season start
UC01
Workshop

Live MMM session. Context, not software.

→
UC02
Purchase

School / program buys team access (out of band in v1).

→
UC03
Admin provisions

School, team, unique join code, access start/end.

→
UC04
Coach login

Separate coach account. Receives team code.

→
UC05
Build season

Set weeks, pick topics, order modules — or Use Recommended Season.

→
UC06–07
Athletes join

Self-signup. Code binds athlete to the correct team.

→
UC08
Season begins

Weekly unlock clock starts. Training is live.

B · Athlete weekly loop
UC09
Unlock this week’s module

Chosen day (e.g. Monday). Home shows only this week: Mental Rep + check-in.

↓
UC10
Notify athlete

“Your Mental Rep for this week is ready.”

↓
UC11 Mental Rep — 5–8 min, cap 10 — same shape every week
11A
Question

30 sec check-in prompt

11B

2–3 min video

11C
Interact

Scenario / activity

11D

Personal tool / phrase

11E

↓
UC12
Pulse check-in

30–60s · six 1–5 scales · stored private

UC13
View progress

e.g. 8/12 reps · optional 4-week streak

UC14
Check-in reminder

“Don’t forget your weekly check-in.”

↻ Next week → UC09 unlock. Loop runs for the length of the coach-built season.

UC15 Aggregate Pulse · strip identity

YES · team only
C · Coach weekly loop
UC16
Team Pulse dashboard

Averages /5, week-over-week arrows, n of n checked in. Team as a whole — not a roster of feelings.

↓
UC17
Need recommendation

e.g. pressure ↑ two weeks → “Managing Pressure” + 5-minute coach reset activity.

↓
UC18
Completion dashboard

Team % and who finished / not. Participation is visible. Answers are not.

↓
UC19
Weekly coach tool

Conversation starter matching this week’s athlete module. Coach participates, not only assigns.

↓
UC20
Notify coach

“73% of your team has completed this week’s Mental Rep.”

D · On-demand athlete
UC21
Mental Toolbox

Before competition, after a bad performance, confidence, pressure, mistakes, communication, motivation, overthinking.

UC22
Game Day · I Need Help With…

Home shortcuts. Not tied to the weekly unlock. Available anytime after join.

E · Admin (continuous)
UC23
Content CMS

Add/edit/delete modules, videos, questions, interactive activities. No developer required.

UC24
Library extras

Mental Toolbox items and matching coach resources.

UC25
Ops

Manage coaches, reset passwords/accounts, access windows, codes.

UC26
Platform metrics

Athletes, active teams, completion, team Pulse (aggregated).

F · Notifications

Athlete: UC10 Rep ready · UC14 check-in due
Coach: UC20 team completion %
Channel: push if native app; otherwise email/in-app.

G · Privacy gate
UC27 Decision

After every athlete write: is this participation, or a private response?

Participation → coach

Completed / not complete. Team Pulse averages. Check-in count. Recommended resource.

Private → lock

Reflections, 1–5 scores, toolbox use. Admin may see operational aggregates, not a counseling file.

Out of flowchart / v1

Payments, athletic-director multi-team, parent portal, Mental Reps unlocking toolbox items, anonymous mental-health disclosure (do not build).
